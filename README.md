# ti-tms9918

The Texas Instruments TMS9918A video display processor and its 9928A/9929A variants.

| Crate | Registry |
|---|---|
| [`emu198x-ti-tms9918`](crates/emu198x-ti-tms9918) | [crates.io](https://crates.io/crates/emu198x-ti-tms9918) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the ColecoVision, Memotech MTX, MSX, Sega SG-1000, Sord M5, Spectravideo and Tatung Einstein.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
